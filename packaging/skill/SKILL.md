# 超昼夜节律计时器技能 (Codex Ultradian Rhythm Skill)

本技能允许 Codex 用户控制本地的超昼夜节律专注计时器。该计时器在后台独立运行，通过 macOS 系统通知与声音提醒阶段切换。

## 系统约束与指令

1. **绝对禁止模拟计时**：大模型**绝对不能**通过多轮对话或等待来“假装”计时。所有启动、查询、暂停、恢复和停止操作必须**直接调用本地的 `ultradian` 命令行工具**。
2. **命令执行**：始终通过执行本地终端命令 `ultradian <subcommand>` 并解析其输出反馈给用户。
3. **周期预设**：
   - **Start 25/5**: 专注 25 分钟，休息 5 分钟（适合快速启动）
   - **Flow 50/10** (默认): 专注 50 分钟，休息 10 分钟（适合经典心流）
   - **Deep 90/20**: 专注 90 分钟，休息 20 分钟（适合深度专注）
4. **专注意图与目标（Goal）规则**：
   - 每次启动专注周期必须提供非空目标，并通过 `--goal-stdin` 从标准输入传递；不要把目标拼进 `--goal "..."` 这样的 shell 命令字符串。
   - 通过 shell 调用时，先按 POSIX 单引号转义规则构造一个完整的 shell 参数。例如 `it's` 必须写成 `'it'\''s'`。再用 `printf '%s' '<安全引用后的目标>' | ultradian start <preset> --goal-stdin`。目标只作为数据，不得使用 `eval`、双引号插值或未加引号的 heredoc。
   - **已有明确目标或可推断**：如果用户的实际目标可以从请求或上下文中直接推断（例如“开始写登录模块”、“专注看论文 50分钟”），将其原话或精炼为准确简明的内容传入标准输入。
   - **未知目标**：如果完全没有获知用户的具体目标（例如用户仅输入“开始专注”、“开启计时”），**绝对不要凭空捏造通用目标（如“日常工作”、“专注任务”等）**。在执行启动命令前，必须先向用户发起一次简短提问获取具体目标。
5. **无明确预设时的呈现规则**：当技能在没有明确预设的情况下被调用时（例如用户询问如何开启专注，或要求列出选项时），必须向用户精准且仅呈现三个选项：`Start 25/5`, `Flow 50/10 default`, `Deep 90/20`。如果用户仅表达了开始意图并提供了目标，但未指定任何周期预设，则默认以 `Flow` 模式启动。

## 自然语言映射规则

当用户提出以下意图时，必须将其映射为具体的终端命令：

| 用户自然语言意图 | 映射执行的本地命令 | 说明 |
| :--- | :--- | :--- |
| “开始专注 [目标]” / “开始计时 [目标]” / “开启专注 [目标]” | `printf '%s' '<安全引用后的目标>' | ultradian start flow --goal-stdin` | 默认启动经典 Flow 50/10 周期（若无已知目标须先询问） |
| “开始 25/5 [目标]” / “快速专注 [目标]” / “Start [目标]” | `printf '%s' '<安全引用后的目标>' | ultradian start start --goal-stdin` | 启动 Start 25/5 预设 |
| “开始 50/10 [目标]” / “心流模式 [目标]” / “Flow [目标]” | `printf '%s' '<安全引用后的目标>' | ultradian start flow --goal-stdin` | 启动 Flow 50/10 预设 |
| “开始 90/20 [目标]” / “深度专注 [目标]” / “Deep [目标]” | `printf '%s' '<安全引用后的目标>' | ultradian start deep --goal-stdin` | 启动 Deep 90/20 预设 |
| “强制/替换开始专注 [目标]...” | `printf '%s' '<安全引用后的目标>' | ultradian start <preset> --goal-stdin --replace` | 覆盖当前已激活的周期强制重新开始 |
| “暂停专注” / “暂停” | `ultradian pause` | 暂停当前计时，保留剩余秒数 |
| “恢复专注” / “继续工作” / “继续” | `ultradian resume` | 从暂停处恢复计时 |
| “停止专注” / “结束专注” / “停止” | `ultradian stop` | 停止当前周期，清除所有状态回到空闲 |
| “重复专注” / “再来一次” / “重新启动” | `ultradian repeat` | 使用上一周期相同的预设启动一次新周期 |
| “查看状态” / “专注状态” / “进度” | `ultradian status` | 查询当前周期状态与剩余时间 |
| “测试通知” | `ultradian notify-test` | 测试 macOS 通知是否可达 |

## 状态呈现与应答模板

在调用 `ultradian status` 后，将输出的信息精炼友好地用中文呈献给用户：
- 如果计时器处于“运行中”，给出剩余时间及截止时间。
- 如果计时器处于“已暂停”，提示剩余时间以及如何通过“继续”恢复。
- 如果计时器处于“空闲”或“已完成”，向用户推荐启动经典 `Flow 50/10` 周期。
